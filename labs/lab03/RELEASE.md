# Лабораторная работа № 3: агентная модель Daisyworld

## Общее описание

В работе воспроизведена модель Daisyworld из главы 3 практикума: чёрные и
белые маргаритки изменяют альбедо клеток, локальную температуру и тем самым
вероятность дальнейшего размножения. Базовые, динамические и параметрические
опыты выполнены в Julia 1.11 с Agents.jl.

## Состав исследования

| Группа | Сценарии | Результат |
|---|---:|---|
| Пространственные состояния | 2 | шаги 0, 5, 45 и четыре набора параметров |
| Динамика численности | 2 | базовая и четыре 1000-шаговые траектории |
| Изменение светимости | 2 | живая система, безжизненный контроль и четыре набора параметров |
| Анимация | 1 | 60 кадров, 10 кадров/с |

## Основные результаты

| Показатель | Значение |
|---|---:|
| Агенты на шаге 45 | 900 |
| Чёрные / белые на шаге 1000 | 475 / 424 |
| Пики численности | 532 / 498 |

| Температура безжизненного контроля при `SL=2` | 92,77 °C |
| Максимальное снижение перегрева биотой | 62,32 °C |
| Автоматические проверки | 28 из 28 |

## Воспроизводимость

`make setup` закрепляет окружение, `make run` выполняет семь сценариев,
`make notebooks` создаёт выполненные IPYNB, `make docs` собирает HTML,
`make test` запускает тесты, а `make verify` проверяет комплектность форматов.

Релиз содержит законченное выполнение первой лабораторной работы по
имитационному моделированию.

## Результат

- Реализована задача Коши `du/dt = αu` и аналитическая проверка.
- Для базового опыта относительная ошибка составила `4,40·10⁻⁶`.
- Исследованы пять значений `α` от `0,1` до `1,0`.
- Подтверждена зависимость времени удвоения `T₂ = ln(2)/α`.
- Пройдены 3 автоматических теста.

# Лабораторная работа № 1: модель экспоненциального роста

## Общее описание

В лабораторной работе реализована и проверена модель экспоненциального роста
`du/dt = αu`. Численное решение построено методом `Tsit5`, сопоставлено с
аналитической формулой и исследовано на сетке из пяти значений коэффициента
роста.

## Цели

| Задача | Реализация |
|---|---|
| Решение задачи Коши | `ODEProblem` и `Tsit5` |
| Аналитическая проверка | `u(t) = u₀e^(αt)` |
| Параметрический опыт | `α = 0,1; 0,3; 0,5; 0,8; 1,0` |
| Воспроизводимое сохранение | CSV и JLD2 через DrWatson |
| Производные форматы | JL, QMD, IPYNB и HTML из Literate-сценариев |

## Реализованные возможности

| Возможность | Результат |
|---|---|
| Базовый расчёт | 101 сохранённая точка на `t ∈ [0, 10]` |
| Сравнение с точным решением | относительная ошибка `4,40·10⁻⁶` |
| Сканирование параметра | пять независимых наборов результатов |
| Время удвоения | проверена зависимость `T₂ = ln(2)/α` |
| Бенчмарк | 100 запусков для каждого значения `α` |
| Автоматическая проверка | 3 теста завершены успешно |

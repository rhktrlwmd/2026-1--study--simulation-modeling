# Лабораторная работа № 1

**Тема:** подготовка рабочего окружения и исследование модели
экспоненциального роста.

**Автор:** Исаева Зарина Исмайилбековна  
**Студенческий билет:** 1132232882

## Состав

- `project` — воспроизводимый Julia-проект, два литературных сценария,
  выполненные Jupyter-ноутбуки, данные и графики;
- `report` — исходник QMD и собранные версии отчёта в DOCX и PDF;
- `presentation` — исходник QMD и собранные версии презентации в HTML и PDF;
- `image` — 15 иллюстраций, распределённых по семи тематическим группам.

## Воспроизведение вычислений

```bash
cd project
julia --project=. -e 'using Pkg; Pkg.instantiate()'
make all
```

Команда последовательно формирует Julia-скрипты, QMD и IPYNB, выполняет
базовый и параметрический эксперименты, собирает HTML-документы и запускает
автоматические тесты.

Описание версии приведено в [CHANGELOG.md](CHANGELOG.md), состав релиза — в
[RELEASE.md](RELEASE.md).
